# LifeML: Life Expectancy Prediction Pipeline

A professional end-to-end machine learning project to predict Life Expectancy based on WHO health and socio-economic data.

## 🚀 Project Overview
This project implements a full ML pipeline—from raw data ingestion to an executive Power BI dashboard—demonstrating industry-standard data engineering and predictive modeling.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Libraries:** Pandas, Scikit-Learn, SHAP, Matplotlib, Seaborn
- **Visualization:** Power BI
- **Environment:** Jupyter Notebooks (Exploration), Python Scripts (Production)

## 📂 Folder Structure
- `data/`: Raw and processed datasets.
- `src/`: Production-ready Python modules for preprocessing, training, and evaluation.
- `notebooks/`: Exploratory Data Analysis (EDA) and prototyping.
- `models/`: Serialized trained models.
- `reports/`: Dashboard and performance reports.

## 📈 Goals
- Achieve a high R² score (Target: ~0.83).
- Implement professional data imputation and outlier treatment.
- Provide model explainability using SHAP values.
- Deliver actionable insights via an executive Power BI dashboard.
